# Design Principles (Permanent)

These principles define VIBETech’s UX/visual philosophy.

## Beautiful over busy

UI should look premium and intentional. Avoid clutter.

## Simplicity wins

Every screen should answer one question.

Reduce cognitive load with clear labels and progressive disclosure.

## Complexity belongs in the backend

If a concept is hard for users, it should be handled behind stable orchestration and contracts.

The UI should present outcomes and decisions in plain language.

## Every screen answers one question

No multi-purpose dashboards.

If a screen has multiple purposes, it fails the user.

## Human language only

Avoid internal/technical terms. Translate business concepts into understandable language.

## Enterprise software should feel premium

Spacing, typography, and interaction patterns should communicate reliability.

## Accessibility by default

Assume users rely on keyboard navigation, screen readers, and high-contrast modes.

## Desktop-first, responsive always

We design for power users first (desktop), then ensure responsive behavior for smaller screens.

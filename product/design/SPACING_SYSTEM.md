# Spacing System

Defines the permanent spacing rhythm for VIBETech.

## Foundations

- Use a **4px base grid** conceptually.
- Maintain consistent whitespace to communicate reliability.
- Prefer whitespace over lines to separate sections.

## Page margins

- Desktop:
  - Horizontal content padding: **40px** per side (`px-10`).
  - Vertical entry padding: **48px** per major section (`py-12`).
- Mobile:
  - Reduce horizontal padding so content remains readable without edge collisions.

## Section spacing

- Between major screen sections:
  - Use `48px` rhythm to create a calm, “premium scroll”.
- Between small blocks inside a card:
  - Use `16px–24px` increments depending on content density.

## Card padding

- Standard information cards:
  - Outer padding: `24px` (`p-6`) as default.
  - Larger premium cards: `32px` (`p-8`) where needed.
- Inner card blocks:
  - Keep consistent label/value spacing using small increments.

## Button spacing

- Primary CTAs:
  - Use larger vertical padding and rounded corners for dominance.
- Secondary buttons:
  - Should match the same height rhythm as badges and chips where possible.

## Vertical rhythm

- Use consistent vertical gaps:
  - Tight: ~`12px`
  - Standard: ~`16px`
  - Comfortable: ~`24px`
  - Spacious: ~`32px` and above

## Whitespace philosophy

- The interface should feel “breathe-able”.
- Avoid compressing content into dense blocks.
- Keep governance labels visually clustered but not cramped.

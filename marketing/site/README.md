# Hostinger marketing site upgrades

Drop-in sections for `vtechdevelopment.com` (Hostinger). Keep the existing hero/nav if you already have them — merge the blocks below, or replace the page with [`index.html`](./index.html) as a full preview.

## What's included

1. **Product nav CTAs** → `app.vtechdevelopment.com` (AI OS) + `social.vtechdevelopment.com` (Social Checker)
2. **Why VibeTech** — adopt → implement → stay differentiation
3. **Starting-at rates** — public floor prices only (edit `STARTING_AT` in `site.js`)
4. **3-question qualifier chatbot** → maps to a service lane
5. **Interactive ROI calculator** — hours, wage, volume → monthly savings vs starting-at cost

## Deploy

1. Upload `index.html`, `site.css`, `site.js` to Hostinger (or paste sections into the live theme).
2. Update floor prices in `site.js` before publishing.
3. Point inquire CTA mailto / form endpoint to your sales inbox.
4. Upload vanity redirects from [`../hostinger-dropin/`](../hostinger-dropin/).

## Note on prices

These are **marketing floor prices**, not the internal rate sheet. Sales reps keep the full card offline.

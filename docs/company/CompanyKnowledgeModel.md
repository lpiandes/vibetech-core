# CompanyKnowledgeModel.md

## Definition

`CompanyKnowledge` is the reusable guidance library employees use while preparing work.

It includes:
- FAQs (common questions and approved explanations)
- policies (response expectations, privacy expectations, governance boundaries)
- templates (message structures and formatting conventions)
- listings/service info/pricing (industry-specific offering details)
- brand voice and writing preferences
- scripts (approved talk tracks)
- preferences (tone, length, escalation thresholds)

## What knowledge is for

Knowledge provides stable language so employees deliver consistent, governed communication.

It also reduces the burden on owners to write everything upfront:
- owners can add knowledge over time
- employees can start with sensible defaults

## Knowledge boundaries

Knowledge is:
- guidance and approved phrasing
- reusable instructions

Knowledge is not:
- workflow execution code
- vendor-specific logic
- runtime orchestration rules

## Suggested knowledge categories by industry

Property Management:
- response policy for new inquiries
- availability and walkthrough scheduling guidance
- HOA and timeline guidance scripts

Law Firm:
- case update response conventions
- document checklist conventions
- governance and escalation phrasing

Dentist:
- intake and consultation response conventions
- appointment rescheduling guidance
- treatment explanation style

Med Spa:
- membership benefits and update conventions
- consultation follow-up scripts
- pricing transparency guidance

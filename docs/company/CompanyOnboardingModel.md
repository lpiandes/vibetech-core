# CompanyOnboardingModel.md

## Definition

Progressive onboarding is how a company becomes operational inside VIBETech.

The key principle: owners should not enter everything upfront.
VIBETech should feel like training Digital Employees, not configuring software.

## Minimum onboarding (MVP)

The minimum steps required to start:
1. Business type / industry
2. Company name
3. First employee goal (what the first Digital Employee should achieve)

With only these three inputs:
- employees can start producing governed work
- owners can refine behavior over time using knowledge and policies

## Progressive onboarding (guided setup)

After the minimum onboarding, the platform guides setup in order of leverage:
1. Connect website (optional, if website intake is desired)
2. Upload knowledge (FAQs, templates, scripts, and brand voice)
3. Connect email (optional)
4. Connect CRM (optional)
5. Import contacts (only if you use CRM)
6. Configure approval rules (governance boundaries)

## Why this onboarding order

- Employees can begin without vendor coupling.
- Knowledge unlocks consistent professional communication.
- Approval rules create safe governance.
- Integrations add convenience after the core behavior is trustworthy.

## What “good progress” looks like

At each stage, the system should:
- show the employee’s next step
- explain what knowledge/policy is missing (in plain language)
- enable testing with example inquiries before live connections

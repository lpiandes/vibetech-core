# Post-pilot backlog

**Status:** Parking lot. Do not build while [DEVELOPMENT_FREEZE.md](./DEVELOPMENT_FREEZE.md) is active unless an item becomes a pilot-blocking exception.

Items land here from operator root-cause classifications and partner feedback — not from imagined product expansion.

---

## Explicitly deferred

- New verticals / industry packs  
- Marketplace  
- Campaigns / ads expansion  
- CRM feature parity as primary product  
- Customer-facing visual automation builders  
- Global autonomy switches  
- Sophisticated cost analytics beyond the human-time ledger + weekly scorecard  
- Cosmetic empty-state redesigns  
- Package catalog expansion  

---

## Capture rule

When an operator closes a case, if the fix is not in the Allowed freeze table, add a one-line backlog entry here with:

- Partner  
- Root cause  
- Symptom  
- Proposed fix class (rule / integration / product / permanent human)  
- Date  

Promote to engineering only after the same class repeats across partners or blocks SLA.

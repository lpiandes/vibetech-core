# Product Constitution (Permanent Rules)

Authoritative full document:
`docs/product/VIBETECH_PRODUCT_CONSTITUTION.md`

Companion (how we build / locked contracts):
`PLATFORM_CONSTITUTION.md` → `docs/architecture/VIBETECH_PLATFORM_CONSTITUTION.md`

Short permanent rules:

1. VIBETech is an AI Operating System — owners hire an operating team, not software.
2. The only customer promise: tell us → recommend → approve → live → talk to VIBETech.
3. The owner supervises; AI operates; humans approve; AI executes.
4. Conversations replace configuration — Ask VIBETech is the primary interface.
5. Everything important is explainable and approved; Business Memory is the source of truth.
6. One product — never parallel Homes, Builders, installs, or ways to the same goal.
7. Architect is not a product; it is VIBETech planning with the owner (one lifecycle).
8. Mission Control, DNA, Assembly, Pipeline, Launch, Builder are engineering terms — never owner language.
9. Extend locked architecture; never fork it for UI convenience.
10. If it exposes internal machinery, it is the wrong direction.
